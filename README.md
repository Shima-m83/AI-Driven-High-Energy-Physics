# AI-Driven High-Energy Physics

Course assignments and project work completed as part of the **AI-Driven High-Energy Physics** course.

This repository documents my work applying artificial intelligence and deep learning techniques to problems in particle and high-energy physics, with a particular focus on **PyTorch, self-supervised learning, representation learning, and foundation models for scientific discovery**.

## About the Course

**AI-Driven High-Energy Physics** introduces students and researchers to the application of artificial intelligence techniques within particle and high-energy physics.

The course combines:

- theoretical foundations,
- practical problem-solving,
- AI and deep learning methods,
- applications to high-energy physics datasets and simulations,
- applied research assignments and projects.

The official course materials are available at:

[AI-Driven HEP Course Materials](https://github.com/AI-Driven-HEP/Course-Materials)

## Repository Contents

This repository contains:

- Completed course assignments
- PyTorch-based exercises and implementations
- A project on **Foundation Models in High-Energy Physics**
- A review of **PoLAr-MAE**, a masked autoencoder for LArTPC data
- Project presentation materials
